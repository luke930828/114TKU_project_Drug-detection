🌐 步驟一：加入團隊的 Tailscale 虛擬內網 (最重要！)
因為你的專案中呼叫的都是 100.x.x.x 這種開頭的 IP（例如 NLP 引擎是 100.69.185.94），這是 Tailscale 專屬的虛擬區域網路 IP。

在新電腦上下載並安裝 Tailscale。

開啟 Tailscale，登入你們團隊約定好的同一個組織帳號。

驗證連線： 打開新電腦的終端機 (cmd/PowerShell)，輸入 ping 100.122.162.47（爬蟲同學的 IP）。如果有收到回覆，代表你的新電腦已經成功連上團隊的內網了！

🐍 步驟二：安裝 Python 與必備套件
確認新電腦已經安裝 Python (建議版本 3.10 以上)，並且在安裝時有勾選「Add Python to PATH」。

把你的「防毒後端瘦身」專案資料夾複製到新電腦上（可以透過隨身碟、Git，或是前面提過的 scp 指令）。

在新電腦的 VS Code 打開這個專案資料夾，開啟終端機，執行以下指令把所有用到的工具安裝起來：

在新電腦輸入 pip install -r requirements.txt 一鍵安裝

🗄️ 步驟三：搞定 MySQL 資料庫連線
這是換電腦最常卡關的地方！在你的 database.py 中，資料庫的連線網址寫著：
mysql+pymysql://root:MySQLdrug2026@localhost:3306/drug_prevention_db


選擇 B (資料庫各自獨立)：
如果你希望新電腦有一個自己乾淨、獨立的資料庫用來測試。那你必須在新電腦上：

安裝 MySQL Server。

將 MySQL 的 root 密碼設定為 MySQLdrug2026。

進入 MySQL，手動建立一個名為 drug_prevention_db 的空資料庫。
在 MySQL 建立一個空的空資料庫：
執行:
CREATE DATABASE drug_prevention_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

🚀 步驟四：啟動伺服器
當網路、套件、資料庫都準備就緒後，在新電腦的終端機輸入：

Bash
uvicorn main:app --reload
因為你在 database.py 中有寫自動建表的語法 (Base.metadata.create_all)，只要連線成功，系統就會自動幫你把所有表格（使用者、黑名單、AI 分析結果等）建立起來。

看到綠色的 Application startup complete.，就可以打開 http://localhost:8000/docs 測試呼叫其他同學的引擎了！


新電腦啟動最終確認清單
資料庫已準備就緒： 確保已經在新電腦的 MySQL 中，手動建立好名為 drug_prevention_db 的空白資料庫。

虛擬內網已連線： 確保新電腦已經安裝並登入 Tailscale，且拿到了 100.x.x.x 的專屬 IP，這樣 YOLO 和爬蟲引擎才能找得到你。

環境套件已安裝： 確認已經在新電腦的終端機執行過 pip install -r requirements.txt，確保 FastAPI、SQLAlchemy 等套件完全同步。

使用正確的指令啟動： 記得只開一個終端機視窗，輸入終極啟動指令 uvicorn main:app --host 0.0.0.0 --port 8000 --reload。
